# Standalone source build and installation

Use [build from source](../../docs/build-from-source.md) for current commands
and [installation and recovery](../../docs/source-install-and-upgrade.md) for
separately authorized local installation. Contributor tests/builds are source
proof only; packaging, installation and provider acceptance are separate actions.
Current settings use schema v4 plus generation-addressed Keychain items. There
is no plaintext configuration importer. Do not inspect live credentials to test.
Signed public delivery follows [release preparation](../../docs/releasing.md)
after explicit signing/notarization and publication approvals.
