# Security policy

## Supported versions

Only the current `main` source is considered for security fixes. This unsupported source alpha has no released or supported binary version and no security-update SLA.

## Report privately

Do not open a public issue for a suspected vulnerability or include credentials, interview data, or exploit details in a pull request. Use GitHub’s **Report a vulnerability** private security-advisory form for this repository. If that form is unavailable, contact the repository owner privately through the Frameyard contact associated with the repository and disclose only enough information to establish a secure follow-up channel.

Reports should identify the affected commit, impact, reproduction conditions using synthetic data, and any suggested mitigation. Never test against another person’s Recall, ngrok, Hermes, Teams, SSH, or Keychain resources.
